# État et cotation

Une intégration charge l état propre au pool puis produit une cotation pour un montant entrant. Le code distingue les opérations coûteuses liées aux changements d état des calculs rapides répétés pendant la recherche de route.

Cette séparation améliore la prévisibilité du moteur d agrégation.
