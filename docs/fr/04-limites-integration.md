# Limites d intégration

Une intégration AMM doit rester cohérente avec l état on-chain et les décimales du token. Les erreurs de désérialisation, de frais ou de fraîcheur des comptes peuvent produire une mauvaise route.

Ce parcours couvre les mécanismes visibles du dépôt. Aucune installation, compilation ou exécution n a été réalisée ; les tests présents sont la référence pour une vérification ultérieure.
